# Matcher: Анализ и сопоставление навыков в вакансиях и резюме (T1)

Проект предназначен для извлечения, анализа и классификации профессиональных навыков (skills) из текстов вакансий и резюме, а также для автоматического расчета релевантности и метрик матчинга с использованием TF-IDF.

## Структура проекта

T1_1/
├── analysis/                      # Модули анализа данных, построения графов и тестирования
│   ├── find_test_matching.py      # Поиск и отбор примеров для тестового сопоставления
│   ├── matcher_category_tfidf.py  # Матчер с учетом категорий навыков на базе TF-IDF
│   ├── matcher_tfidf.py           # Основной скрипт матчинга резюме и вакансий (TF-IDF)
│   ├── skills_dict_v3.json        # Локальный словарь навыков (версия 3) с категориями
│   ├── skills_graphs.py           # Визуализация и построение графов взаимосвязей навыков
│   ├── test_matching_on_dataset.py# (Пример 2 из файла "вывод") Запуск пакета тестов матчинга на тестовых датасетах
│   ├── text_resume.txt            # Тестовый пример текста резюме
│   └── text_vacancy.txt           # Тестовый пример текста вакансии
│
├── datasets_and_skills/           # Данные, словари навыков и аналитическая документация
│   ├── analysis_skills_v1_to_v3.md# Аналитика эволюции и изменений словарей навыков (v1 -> v3)
│   ├── datasets/                  # Папка для локальных датасетов (файлы *.csv игнорируются Git)
│   ├── README.md                  # Дополнительное описание раздела навыков
│   └── skills/                    # Версии словарей навыков и диаграммы
│       ├── skills_dict.json       # Первая версия словаря навыков
│       ├── skills_dict_v2.json    # Вторая версия словаря навыков
│       ├── skills_dict_v3 copy.json # Третья версия словаря навыков
│       ├── skills_dict_v3.json    # Актуальная третья версия словаря навыков с категориями 
│       └── diagrams/              # Графики и диаграммы распределения навыков
│           ├── chart_v1.png

│           └── chart_v3.png

├── docs/                          # Отчетная документация и формулы

│   └── формула.odt / формула.pdf  # Математическое описание и формулы алгоритма сопоставления
│
├── matcher_tfidf.py               # Корневой исполняемый модуль TF-IDF матчинга
└── vector_test.py                 # Скрипт тестирования векторных представлений текстов
