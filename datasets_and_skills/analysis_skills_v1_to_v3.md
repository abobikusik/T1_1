# Анализ эволюции словаря навыков: v1 → v2 → v3

> Дата анализа: 05.10.2026 · Файлы: `skills_dict.json` (v1), `skills_dict_v2.json` (v2), `skills_dict_v3.json` (v3)

## 1. Исходные данные

Словарь навыков расширялся последовательно по **4 датасетам**:

| № | Датасет | Источник | Содержимое | Строк | Размер |
|---|---|---|---|---|---|
| A | `niktigerbill/resume-job-description-fit-ru` | HuggingFace | RU-пары «резюме + вакансия» с меткой соответствия (No/Potential/Good Fit) | 8 000 пар | 56 МБ (parquet) |
| B | `vyacheslavpanteleev1/hhru-it-vacancies-from-20211025-to-20211202` | Kaggle | IT-вакансии HH.ru (окт–дек 2021): название, ключевые навыки, описание | 48 564 | 188 МБ (CSV) |
| C | `sameelie/resume-hh` | Kaggle | Резюме с HH.ru: опыт работы, должности, образование | 44 576 | 455 МБ (CSV) |
| D | `saugataroyarghya/resume-dataset` | Kaggle | Англоязычные резюме: skills, objective, responsibilities, positions | 9 544 | 17 МБ (CSV) |

Всего просканировано **~110 000 записей / ~374 000 текстовых полей** (RU + EN).

## 2. Методология

1. **Токенизация** текстов (слова, включая `c#`, `1с`, `44-фз`, `html/css`) и подсчёт частот униграмм и биграмм по каждому корпусу.
2. **Кандидаты в навыки**: список из ~250 терминов (по наблюдениям в корпусах и типовым стекам) проверялся на реальную встречаемость во всех 4 датасетах.
3. **Порог включения**: термин добавлялся при значимой частоте (обычно ≥ 15 упоминаний) и различительной способности; шумные короткие алиасы (`pr`, `r`, `ad`, `go` без контекста) отсекались.
4. **Контроль качества**: проверка уникальности имён, последовательности id, отсутствия пересечения алиасов между навыками (3 конфликта обнаружено и устранено при сборке v3).
5. **Замер покрытия**: для каждой версии подсчитывалось число уникальных найденных навыков на текст с проверкой границ слов.

## 7. Проверки качества

- ✅ id последовательны (1…377), дубликатов имён нет;
- ✅ конфликтов алиасов между навыками нет (при сборке v3 найдено и исправлено 3: `b2b продажи`, `аналитический склад ума`, `исполнительность`);
- ⚠️ осознанные объединения: Docker ↔ Docker Compose, Виртуализация ↔ VMware/Proxmox, SIEM ↔ Splunk — близкие термины намеренно не дублируются, чтобы не задваивать счёт;
- ⚠️ короткие алиасы (`ux`, `ui`, `sas`, `ios`) могут давать редкие ложные срабатывания — в боевом использовании стоит применять слово-граничный матчинг (как в замерах) и при необходимости контекстные правила.

## 8. Выводы

1. **v3 покрывает ~3.3 навыка на текст против 1.3 у v1** и находит навыки в 52% текстов против 37% — почти полное покрытие структурированных IT-текстов (96–100%) и хорошее для «сырых» резюме (86%).
2. Расширение шло от IT-центричного (v2) к **универсальному словарю рынка труда РФ** (v3): добавлены десятки не-IT доменов, которые встречаются в массовых резюме HH.ru.
3. Все добавления **обоснованы реальной частотностью** в корпусах, а не гипотезами, что снижает риск «мёртвых» навыков.

## 9. Как использовать

```python
import json
skills = json.load(open("skills_dict_v3.json", encoding="utf-8"))

def detect(text, skills):
    t = " " + text.lower() + " "
    found = set()
    for s in skills:
        for a in s["aliases"]:
            i = t.find(a)
            while i != -1:
                b, e = t[i-1], t[i+len(a)]
                if not (b.isalnum() or e.isalnum()):
                    found.add(s["name"]); break
                i = t.find(a, i+1)
    return found

print(detect("Опыт работы: Python, Django, PostgreSQL, Docker", skills))
# {'PostgreSQL', 'Docker', 'Python', 'Django'}
```
